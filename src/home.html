Preview for Apple Silicon Macs

Stainless

A free, Chromium-based browser for developers, agent builders and privacy-conscious people.

Real Chromium, built from a pinned source revision with Google's built-in services removed and an opt-in updater. The goal: use the web without ads, sponsored placements, behavioral tracking or a mandatory account.

Download a preview Read the install guide

Previews are unsigned, unnotarized prereleases for macOS 13 or newer. Only macOS 26.6 has been verified. See project status.

Why Stainless

  • Real Chromium, not a wrapper

    Stainless builds Chromium's full chrome target from a pinned revision. It isn't Electron, a system WebView or a rebranded binary, and it keeps Chromium's sandboxing, site isolation and certificate validation.

  • No Google services built in

    Sign-in, sync, Safe Browsing and other Google-backed services are removed. Search falls back to DuckDuckGo until you pick a provider, metrics consent is forced off and Stainless adds no telemetry endpoint.

  • Separate from Chrome

    Stainless has its own app identity, profile folder and Keychain items, and never imports Chrome or Chromium data implicitly.

  • Auditable

    The Chromium revision, toolchains and every downstream patch are pinned and reviewable in the open. Each package ships build manifests, checksums and third-party notices.

In the newest preview

  • Everyday Chromium browsing: tabs and windows, bookmarks, history, find and zoom, downloads, print and PDF, settings, Incognito and DevTools.
  • Built-in Google services removed, with the gaps documented.
  • On-device threat-list blocking and opt-in password breach checks.
  • A separate Stainless profile and Keychain identity, plus managed Standard, Incognito and memory-only Guest profiles with backup, restore and startup Safe Mode.
  • Opt-in automatic updates with hash verification and failed-launch rollback.
  • A command palette (Command+Shift+P), a keyboard shortcut editor and portable keymaps.
  • A read-only resource overview, local-only saved history and stainless:// addresses.
  • Experimental, opt-in self-hosted Web Push and local services for translation, speech, captions and OCR.

Know the tradeoffs

  • Previews are unsigned, unnotarized, Apple Silicon only and still in Phase 1 verification.
  • Google Safe Browsing and Google's password-leak checks are removed. Threat lists block known dangerous domains, but can't scan downloads or recognize new dangerous pages.
  • Automatic updates trust HTTPS and GitHub, not signed update metadata.
  • Widevine and proprietary codecs aren't included.
  • Removing Google services isn't a complete privacy product. Encrypted profiles, privacy containers, fingerprint protection and Tor are later roadmap work.

Install a preview

  1. From Releases, download the newest Stainless-VERSION-macos-arm64.dmg and its SHA256SUMS.
  2. Compare the image's hash with its SHA256SUMS entry: 
    shasum -a 256 Stainless-VERSION-macos-arm64.dmg
  3. Open the image, drag Stainless to Applications, eject the image and launch Stainless from Applications.
  4. If macOS blocks the first launch because the app isn't notarized and your hash matched, try to open it once, then go to System Settings > Privacy & Security and click Open Anyway. Never disable Gatekeeper, and don't open an app that macOS reports as damaged or malware.

Updates, backups, recovery and removal are covered in the macOS install guide.

Build from source

You need an Apple Silicon Mac with full Xcode 26.6 or newer, the macOS 26.5 SDK or newer, an APFS volume, 16 GiB of memory (32 GiB recommended) and at least 100 GiB of free disk. No paid Apple account or signing credential is required.

git clone https://github.com/stainless-browser/stainless.git
cd stainless
./tools/stainless doctor
./tools/stainless bootstrap
./tools/stainless build

doctor checks the Mac, Xcode, SDK, Rust, memory and disk. bootstrap fetches the pinned Chromium and applies the patches, which can take hours. build builds Chromium, ChromeDriver and the updater.

build, test and package launch native macOS processes, so run them only on a dedicated macOS test host or VM. The build guide has the details.

Where Stainless is going

Stainless is a work in progress. Today it's the real Chromium browser for Apple Silicon Macs. Identities, privacy controls, local AI and auditable agents arrive in later phases, and Linux and Windows are later targets.
